### 解耦方案（关键决策，后续维护要遵循）
- 文件 IO：包内**从不写文件**，保存走 `@save` 事件；导出走浏览器 `downloadBlob` / `window.print`。
- 图片：包内**从不落盘**。上传走 `onUpload` prop（默认 FileReader→`data:` URL），
  Crepe `image-block.onUpload` 回退到 `getImageUploader()` 而非字面 `defaultUploader`
  （否则宿主 prop 对粘贴图片路径失效 —— 设计文档此处自相矛盾，按 §2.1 API 契约取前者）。
  本地 src 解析走 `resolveImageSrc`（默认恒等）。`persistImageFile/localizeMarkdown/
  prepareImagesForSave` 等磁盘物化 API 整体删除。
- 设置持久化：`localStorage['typo-md-editor:settings']`（原 Tauri settings.json）；
  语言 key `typo-md-editor:lang`。store id 加前缀 `typo-editor`/`typo-settings`。
- 主题 kind 判定统一到新增的 `src/themes.ts`（THEMES/themeKindMap/isDarkThemeId），
  删掉 `milkdown/setup.ts` 里那份私有 map（消除两处不同步隐患）。
- 丢弃桌面外壳：MenuBar/AppLayout/StatusBar/FileTree/CommandPalette/QuickOpen/
  RecoveryDialog/useTauri/useAutosave/useRecentFiles/useQuickOpen/useWindowTitle/stores/files。
- 保留可选：OutlinePanel、FindDialog、SettingsDialog（open 外置）。

- 上游 `@milkdown/components@7.x` 已自带 caption 修复，但发布的是**转译形态**
  `(_a = node.title) != null ? _a : ""`，补丁脚本原来的 FIXED 正则 `node\.title \?\? "";`
  匹配不到 → 恒报 "nothing to do"。已把 FIXED 扩为同时匹配两种形态

  现在正确输出 "already fixed — skipped"。README 的验证指引同步改写。
